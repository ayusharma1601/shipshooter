# 🚀 Ship Shooter

[![Play Online](https://img.shields.io/badge/Play_Online-WebAssembly-478CBF?style=for-the-badge&logo=godotengine&logoColor=white)](https://ayusharma1601.github.io/shipshooter/)
[![GitHub Repo](https://img.shields.io/badge/GitHub-ayusharma1601%2Fshipshooter-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ayusharma1601/shipshooter)

A classic 2D retro arcade space shooter built with the **Godot Engine** and exported to **HTML5 / WebAssembly** for instant in-browser play. Take control of your ship, dodge incoming hazards, and blast through waves of enemy ships!

---

## 🕹️ Play Online

## 🚀 Features

- **Instant Play in Browser:** Fully exported to WebAssembly and HTML5 Canvas for zero-friction access.
- **Smooth & Responsive Handling:** Tight controls tailored for rapid dodging and precision targeting.
- **Classic Arcade Action:** Continuous enemy waves and score chasing.
- **Lightweight & Fast:** Optimized asset pipeline ensuring rapid load times across all modern browsers.

---

## 🛠️ Built With

- **Engine:** [Godot Engine](https://godotengine.org/)
- **Scripting:** GDScript (gameplay mechanics, player movement, spawning, collision detection)
- **Deployment:** WebAssembly (Wasm) & JavaScript Web Export

---

## 💻 Local Setup & Development

If you want to run or modify the source project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ayusharma1601/shipshooter.git
   ```

2. **Open in Godot:**
   - Download and open [Godot Engine 4.x](https://godotengine.org/download).
   - Click **Import**, navigate to the cloned folder, and select `project.godot`.
   - Press `F5` to run the project.
